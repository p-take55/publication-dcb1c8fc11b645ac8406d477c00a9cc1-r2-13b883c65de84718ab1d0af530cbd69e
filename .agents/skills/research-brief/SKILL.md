# 調査を提案資料にまとめる

1. 調べるテーマ、読者、判断したいことを確認する。
2. 一次情報を優先し、出典と確認日を記録する。
3. 読者（例: 取引先の担当者）と前提条件（例: 予算の上限）を利用者に確認し、その前提で選択肢を比較する。前提が不明な場合は推測せず、資料内に未確定として明記する。
4. 要点、根拠、次のアクションを `references/report-format.md` に合わせて書く。
5. 不確かな記述に断定がないか確認する。
